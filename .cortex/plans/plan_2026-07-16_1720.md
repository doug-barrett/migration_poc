## Implementation Steps

### Step 1: Create `scripts/01_plan.py`

A new Phase 1 script that:

1. **Parses `app_obj_*.wst`** → builds registry `{name: {type, id}}` for all 365 objects
2. **Parses `app_data_*.wst`** (UTF-16LE) → extracts each script block by `SET IDENTITY_INSERT` boundaries
3. **Reassembles script SQL** from `ws_scr_line` entries (handling multi-line values split across WST lines)
4. **For each script, extracts embedded SQL statements** by finding `f"""..."""` and `"""..."""` Python string literals
5. **Parses each SQL statement** to extract:
   - Target table (from `INSERT INTO <db>.<table>` or `MERGE INTO`)
   - Column list (from INSERT column list or UPDATE SET columns)
   - Source table(s) (from FROM/JOIN)
   - Column expressions (from SELECT list — maps target col → source expression)
6. **Maps scripts → target objects** using naming conventions: `UPDATE_X`/`upd_X`/`custom_X`/`drv_X` → object `X`
7. **Strips database prefixes** (`P_BI_EDWTAB_DB.`, `P_BI_STGTAB_DB.`, etc.) to resolve to object names in the registry

### Step 2: Output Files

- **`mapping.csv`** — Column-level lineage: `obj_name, obj_type, col_name, data_type, src_obj, src_col, transform, obj_join`
- **`repo/scripts.csv`** — Raw extracted scripts: `script_name, target_obj, line_count, sql_count`
- **`repo/unmapped_objects.csv`** — Objects with no script (type 6/7/8/18 objects without a matching script — these get column metadata from Snowflake INFORMATION_SCHEMA)

### Step 3: Database Schema Mapping

Map the fully-qualified references found in scripts to Coalesce locations:
- `P_BI_EDWTAB_DB.*` → GOLD (dimension/fact layer)
- `P_BI_STGTAB_DB.*` → SILVER (staging layer)
- `P_BI_LOADTAB_DB.*` / load tables → BRONZE (source layer)

### Step 4: Handle Edge Cases

- Multi-statement scripts (INSERT ALL with WHEN clauses, UPDATE after INSERT)
- MERGE statements (common in SCD2 patterns)
- `Run_*` / `drv_*` scripts that orchestrate but don't contain column mappings (skip)
- Scripts with Python logic between SQL calls (extract just the SQL strings)
- Escaped quotes in SQL (`''` → `'`)
